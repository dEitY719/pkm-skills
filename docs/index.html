pkm-skills

두 개의 외부 서비스에 걸친 개인 지식관리 스킬 네 개. 끝난 AI 세션을 Obsidian vault 에 클립하고, 그 vault 의 동기화 충돌을 풀고, URL 을 Karakeep 에 분류하고 등록한다. pkm 이라는 플러그인 하나로 묶여 있으며 여섯 개 코딩 에이전트 하네스에 설치된다.

Obsidian vault

Obsidian

obsidian-session-clip

끝난 AI 세션 하나를 PARA vault 의 99-Inbox/ai-session/ 아래 markdown 노트 1개로 남기고, 그 파일 하나만 커밋한다. 명시 호출 전용이며 원격은 건드리지 않는다.

AI 세션 → vault 노트
visual guide usage example
Obsidian

obsidian-resolve-conflict

vault 의 git pull 충돌을 분류해 로컬 상태 파일만 자동 해결하고, 노트 본문은 사용자에게 물은 뒤 merge 커밋과 push, 짝 클론 fast-forward 까지 간다.

충돌한 vault → merge 커밋
visual guide usage example

두 스킬은 vault 를 공유하지만 remote 는 공유하지 않는다. session-clip 은 원격에 접속하지 않고, resolve-conflict 는 원격 동기화가 목적이다.

Karakeep

Karakeep

karakeep-classify

살아 있는 List 트리를 읽어 URL 이 어디에 속하는지 근거와 함께 제안하고, 바로 붙여 쓸 후속 명령을 출력한다. 기본값은 dry-run 이라 아무것도 쓰지 않는다.

URL → List 경로 제안
visual guide usage example
Karakeep

karakeep-add

URL 을 지정한 List 에 REST 로 등록하고 빠진 부모 List 를 전부 만든다. 같은 이름의 List 도 같은 URL 의 북마크도 중복 생성하지 않는다.

URL + List 경로 → 등록된 북마크
visual guide usage example

두 스킬은 propose-then-confirm 한 쌍이다. classify 가 판단하고 add 가 쓴다. add 를 --list 없이 부르면 추측하지 않고 classify 로 넘긴다.
